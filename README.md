## Assignments

### Assignment 1 – Security Data Collection

**Part A: Spam Crawler Data Collection**
- Develop a Python-based web crawler to inspect HTML forms.
- Identify form fields and submission methods.
- Collect and document submission results on authorized sites.
- Analyze the effectiveness and limitations of the data collection process.
